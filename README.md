# 回転ナンプレ（仮称）

4×4のマスを対角線で32枚の直角三角形に分け、1〜8を4個ずつ置いたパズルです。5つの正方形を回して数字を並べ替え、正方形5つ・横列4本・縦列4本のすべてに1〜8が1回ずつ入ればクリアです。

ブラウザだけで動く静的サイトです。ビルドは要りません。スマホの縦画面で片手で遊べるように作っています。

## 遊び方

1. 盤面にある5つの丸いハンドル（左上・右上・左下・右下・中央）のどれかをタップします。
2. ハンドルのまわりの8枚の数字が1ステップ回ります。回る向きは画面下の「時計回り／反時計回り」で切り替えます。PCでは右クリックで逆向きに回ります。
3. 13グループすべてに1〜8が1回ずつそろえばクリアです。

ハンドルに触れている間は、回る8枚が強調されます。キーボードでは、Tabでハンドルを選び、Enterで回します（Shift+Enterで逆向き）。Ctrl+Zで元に戻し、Ctrl+Shift+Z（またはCtrl+Y）でやり直します。

## ルール

- 盤面には常に1〜8が4個ずつ、計32個あります。
- 判定するのは次の13グループです。
  - 正方形5つ：回転の中心（4本の線が交わる内側の格子点）を囲む4マス、8枚
  - 横列4本：横に並んだ4マス、8枚
  - 縦列4本：縦に並んだ4マス、8枚
- 中央の正方形は、四隅の正方形と2枚ずつ重なっています。
- クリアはこの条件だけで判定します。完成形は複数あるので、作成時の完成形と一致しているかは見ません。

### モード

| モード | 1回の動き | 一周に必要な回数 |
| --- | --- | --- |
| 45°（既定） | 数字が隣の三角形へ1つずつ移る | 8回 |
| 90° | 正方形ごと90°回る（マスの中の2枚はセットで動く） | 4回 |

モードは問題ごとに固定です。モードを変えると新しい問題になります。

### 難易度と最短手数

難易度は、いちばん近い完成形までの最短手数で決めます。

| 難易度 | 最短手数 |
| --- | --- |
| やさしい | 1〜2手 |
| ふつう | 3手 |
| むずかしい | 4手 |
| 鬼 | 5〜6手 |
| ランダム配置（45°のみ） | 調べない |

問題は次の手順で作ります。逆向きに回せば戻るので、どちらのモードでも必ず解けます。

1. 難易度の範囲から目標の手数 t を選び、完成形を t 手ランダムに崩す。直前の手を打ち消す手と、半周を超えて同じ向きに回し続ける手は選ばない。四隅の正方形は互いに重ならず、回す順番を入れ替えても結果が同じなので、四隅が続くときは番号の小さい順にする。
2. 崩した配置から幅優先探索で、t−1手以内にどれかの完成形へ届くかを調べる。届いたら捨てて作り直す。
3. 残った配置の最短手数はちょうど t 手なので、画面に「最短手数」として表示する。

完成形は複数あるので、探索の目標は「13グループの条件を満たす盤面」すべてです。最初の完成形とは違う完成形にたどり着いてもクリアになります。6手まで調べても、記録する盤面は5手までの約1.7万通り（45°モード）で、探索は数十ミリ秒で終わります。

45°モードではどんな配置からでも解けるので、1〜8を4個ずつ並べるだけの「ランダム配置」も選べます。この場合、最短手数は調べず「—」と表示します。

## 機能

- 手数、経過時間、最短手数、モード、難易度の表示（ページが隠れている間は時間を止めます）。最短手数でクリアすると、そのことも表示します。
- 元に戻す／やり直す（履歴は無制限）、リセット（出題時の配置に戻す）
- 共有：問題のURLをコピーします。形式は `?m=45&s=<32桁>&p=<最短手数>` です。`s` は三角形ID順に並べた32個の数字（各桁1〜8）で、ランダム配置は `p=0` です。
  - 各数字が4個ずつでないURLは、エラーを表示して新しい問題を出します。
  - 読み込んだ側でも6手まで探して最短手数を確かめます（`p` の値は信用しません）。6手以内で解けなければ「7+」と表示します。
  - 90°モードの配置は解けない場合があるので、6手以内で解けない配置には「解けることは保証されません」と表示します。
- 補助表示（設定でオンオフ）：重複がある横列・縦列・正方形の強調、数字ごとの色分け
- 設定とベスト記録（モード・難易度ごとの最少手数と最短時間）を `localStorage` に保存します。保存できない環境でもそのまま遊べます。

## 公開手順（GitHub Pages）

1. このリポジトリを GitHub に push し、`main` ブランチにファイルを置きます。
2. リポジトリの **Settings → Pages** を開きます。
3. **Build and deployment** の Source で **Deploy from a branch** を選び、Branch を **main**、フォルダを **/ (root)** にして Save します。
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます。

## 開発

ローカルで確認するときは、ES Modules を読み込むために HTTP サーバーで開きます（`file://` では動きません）。

```sh
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

ロジックのテストは Node.js（18以降）の組み込みテストランナーで動きます。依存パッケージはありません。

```sh
node --test
```

### 盤面の表し方

- マスは (r, c)、格子点は (x, y) で表します（どちらも0始まり、xが右、yが下）。
- r+c が偶数のマスは「＼」、奇数のマスは「／」の対角線で、上側Uと下側Lに分けます。
- 三角形IDは `(r×4 + c)×2 + h`（Uなら h=0、Lなら h=1）で、0〜31です。
- 正方形を k だけ回すと `next[seq[(i+k) mod 8]] = cur[seq[i]]` になります。seq は正方形の三角形IDを時計回りに並べたものです。45°モードは k=±1、90°モードは k=±2 です。

盤面の大きさと数字の範囲は `js/board.js` の定数にまとめています（v1は4×4と1〜8に固定）。
